The blueprints are written to four frameworks: the <a href={FRAMEWORKS.ngss.home}>Next Generation Science Standards</a>, the <a href={FRAMEWORKS['ccss-math'].home}>Common Core</a> for mathematics and for English language arts and literacy, and the <a href={FRAMEWORKS.c3.home}>C3 Framework</a> for social studies. Each table below lists the standards the set teaches, in grade order.

**What it asks** is a short paraphrase. Follow the code for the standard's own words.

<Aside type="note" title="Where the links go">
- **NGSS** codes open that performance expectation on nextgenscience.org.
- **Common Core** codes open the official PDF at the page the standard is printed on. The Common Core site no longer has a page for each standard.
- **C3** indicators have no pages of their own, so each code opens the framework.

Every NGSS address was opened, and every Common Core standard was found in the PDF by its own wording, on 27 November 2026.
</Aside>

## In the standards library

QuestLab keeps the standards of every US state, the Common Core, NGSS, Canada and the UK in its [standards library](/docs/codebase/standards-library/), and a mission is aligned to items in it. The blueprints have **not** been aligned yet, because none has been generated.

When you generate one from the command line, name its codes with `--standard=` and the generator builds the mission around exactly those. [Running the prompts](/docs/blueprints/run-the-prompts/#on-the-command-line) shows how. To look a code up first:

```bash
php artisan qbl:standards search "fraction as a number on the number line" --grade=3 --subject=mathematics
php artisan qbl:standards history 3.NF.A.2 --jurisdiction=US-CCSS
```

The library also holds each state's own copy of the Common Core and NGSS standards, linked to the original, so one alignment can serve many states.
