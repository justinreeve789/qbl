---
title: "Jump"
description: "Goes to another scene."
---

`type`: `jump`

Load another scene, ending all actions in the current scene (except persistent audio).

Parameter | Type | Default | Description
--------- | ---- |---------| -----------
scene_id | int |  | The scene id to jump to.

More fields:

Parameter | Description
--------- | -----------
spawn_point | Spawn point to arrive at in the target scene.
