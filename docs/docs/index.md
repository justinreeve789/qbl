# QBL JSON Documentation

This document describes the JSON structure for QBL scenario data. QBL scenarios are designed to allow the creation of interactive experiences revolving around the usage of media, including audio, images, text, spritemaps, and video.

Scenarios can be scripted via an end-user app, but on the backend the QBL API outputs the scenario data as a JSON string. The Phaser frontend reads the JSON, and executes the scenario as scripted. Examples of scenario JSON strings are included in this documentation.
